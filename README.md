# Brain-tumor-CNV-classifier

DNA methylation profiling and machine learning has shown powerful ability in classify tumors such as tumors from central nervous systems. The classification was solely performed using DNA methylaion beta values. 

Copy number alterations/variations (CNV) were phonetical in several cancer types that have potential interest for cancer classification/diagnostic. For example, chromosome 7 gain and 10 loss is often seen in glioblastoma; chromosome 1p gain and 19q co-deletion is a CNV marker that differentiate IDH-mutant astrocytoma and IDH-mutant oligodendroglioma. 

I was interested in how much value is CNV in tumor classification, the intuition is that CNV may add value to cancer classification in at least some cancer types such as IDH-mutant, chr 1p19q-codeleted oligodendroglioma. Overall CNV classifier can have an accuracy of ~70% for all CNS tumors.
